# Security

If you discover a security vulnerability in any of my projects, please report it responsibly.

You can report vulnerabilities privately using GitHub's built-in [security advisory feature](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) on the affected repository.

Please do not open a public issue for security vulnerabilities. I will respond within 48 hours and work with you to understand and address the issue.
