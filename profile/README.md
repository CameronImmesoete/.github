# Hi, I'm Cam

Software Engineer at Microsoft. Berkeley Haas EWMBA candidate. I like building things that sit at the intersection of software engineering and business analytics.

## What I'm Working On

**Interactive MBA Calculators.** Browser-based calculators powered by Pyodide (Python running in WebAssembly). The conjoint analysis tool handles full-profile generation, OLS regression, and attribute importance scoring in the browser with zero backend.

- [marketing_calculators](https://github.com/CameronImmesoete/marketing_calculators): conjoint analysis, CLV, break-even, CAC, churn rate, NPS, ROMI
- [macroeconomics_calculators](https://github.com/CameronImmesoete/macroeconomics_calculators): IS-LM, AD-AS, Phillips Curve, fiscal multiplier, exchange rate, BoP
- [microeconomics_calculators](https://github.com/CameronImmesoete/microeconomics_calculators): supply and demand, elasticity, consumer/producer surplus, market equilibrium
